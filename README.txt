CASER DEMO UI

Это визуальный демо-прототип по предоставленному скриншоту:
- тёмная шапка и боковая панель;
- экран апгрейда;
- круговой индикатор;
- инвентарь и сетка предметов;
- адаптивная верстка.

Важное ограничение: апгрейд и вероятность намеренно не являются азартной/денежной механикой. Кнопка используется только как визуальный элемент.
Запуск: откройте index.html в браузере.
